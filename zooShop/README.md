# zooShop
Zoo Shop System

Welcome to the Zoo Shop System! This project is designed to manage and display information about animals in a zoo shop. It allows users to view animals, their pictures, names, types, breeds, and birthdates. Additionally, admins have the ability to create, edit, or delete animals, as well as manage animal types and breeds.

Features

View Animals: Users can see a list of animals with the following details:

Animal name

Animal picture

Type (e.g., Mammal, Bird, Reptile, etc.)

Breed (specific to the animal's species)

Birthdate (the birthdate of the animal)

Admin Features:

Create Animals: Admins can add new animals to the system, including uploading pictures and entering all relevant information.

Edit Animals: Admins can update details for existing animals, such as changing their name, breed, or type.

Delete Animals: Admins can remove animals from the system when needed.

Manage Animal Types & Breeds: Admins can create, edit, or delete animal types and breeds.

Requirements

Admin Authentication: Admins must be logged in to access the admin panel and perform administrative actions.

Animal Picture Upload: Images for each animal must be uploaded to the system in an acceptable format (e.g., .jpg, .png).

Usage


Viewing Animals

Go to the main page to see a list of available animals.

Each animal's name, type, breed, and birthdate will be displayed with an accompanying picture.

Admin Panel

To manage the animals, navigate to the admin panel (only accessible by admins).

From the admin panel, admins can:

Add new animals (with their pictures, types, breeds, and birthdates).

Edit or delete existing animals.

Manage animal types and breeds.
